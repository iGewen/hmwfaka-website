# HmwCard 简介

HmwCard（何慕雯发卡系统）是一套开箱即用的自动发卡解决方案，专为虚拟商品、卡密、激活码等数字产品的自动交付而设计。系统基于 Vue 3 + TypeScript 构建，采用 Docker 容器化部署，让虚拟商品交易变得前所未有的简单。

## 核心能力

HmwCard 围绕"自动发卡"这一核心场景展开，提供端到端的交易闭环能力：

- **自动发卡**：用户付款后系统自动发送卡密，7×24 小时无人值守
- **多渠道支付**：支持微信支付、支付宝、PayPal、Stripe 等主流支付方式
- **即时通知**：新订单、库存预警、异常告警多渠道实时推送
- **安全可靠**：数据加密存储、接口签名验证、防刷防攻击
- **一键部署**：Docker 容器化，一条命令即可启动
- **全端适配**：响应式设计，完美适配 PC、平板、手机

## 适用场景

HmwCard 适用于以下虚拟商品交易场景：

1. **游戏卡密**：Steam Key、游戏激活码、CDKey 等
2. **软件激活码**：付费软件、订阅服务的激活码
3. **充值卡**：话费充值卡、会员充值卡等
4. **课程码**：在线课程、教育平台的激活码
5. **会员码**：网站 / APP 会员、订阅服务
6. **礼品卡**：电商礼品卡、虚拟礼品卡等

## 技术栈

| 技术 | 用途 |
|------|------|
| Vue 3 + TypeScript | 前端框架 |
| Node.js / Bun | 后端运行时 |
| Docker | 容器化部署 |
| MySQL | 数据存储 |
| Redis | 缓存与队列 |
| Nginx | 反向代理 |

## 系统要求

部署 HmwCard 需要满足以下最低配置：

- **服务器**：1 核 CPU / 1GB 内存 / 20GB 硬盘
- **操作系统**：任意主流 Linux 发行版（Ubuntu 20.04+ / CentOS 7+ / Debian 10+）
- **运行环境**：Docker 20.10+ 与 Docker Compose
- **域名**：可选，但推荐配置 SSL 证书
