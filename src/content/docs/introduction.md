# HmwCard 简介

HmwCard（何慕雯发卡系统）是一套开箱即用的自动发卡解决方案，专为虚拟商品、卡密、激活码等数字产品的自动交付而设计。系统支持支付宝、微信支付、PayPal、Stripe 等主流支付渠道，使用 Docker 容器化部署，一条命令即可完成生产环境上线。

## 核心能力

- **自动发卡**：用户付款后系统自动发送卡密，7×24 小时无人值守
- **多渠道支付**：支持支付宝、微信支付、PayPal、Stripe（含 Stripe 内嵌支付宝/微信）
- **卡密管理**：支持批量导入、库存预警、防重复发放
- **管理后台**：商品管理、订单管理、支付配置、统计分析、审计日志
- **安全可靠**：敏感数据 AES-256 加密存储、支付回调签名验证、CSRF 防护、接口限流
- **一键部署**：`install.sh` 自动安装 Docker、配置数据库、申请 SSL 证书
- **响应式前端**：Vue 3 + Vite SSG 预渲染，PC / 平板 / 手机全适配

## 适用场景

1. **游戏卡密**：Steam Key、游戏激活码、CDKey 等
2. **软件激活码**：付费软件、订阅服务的激活码
3. **充值卡**：话费充值卡、会员充值卡等
4. **课程码**：在线课程、教育平台的激活码
5. **会员码**：网站 / APP 会员、订阅服务
6. **礼品卡**：电商礼品卡、虚拟礼品卡等

## 技术架构

### 前端

| 技术 | 用途 |
|------|------|
| Vue 3 + Composition API | 前端框架 |
| TypeScript | 类型安全 |
| Vite 6 + vite-ssg | 构建工具 + 静态站点生成 |
| Tailwind CSS v4 | 原子化 CSS |
| vue-router 4 | 客户端路由 |
| @unhead/vue | SEO 管理 |

### 后端

| 技术 | 用途 |
|------|------|
| Node.js 24 | 运行时 |
| Express | Web 框架 |
| Prisma ORM | 数据库访问 |
| MySQL 8.0 | 业务数据存储 |
| Redis 7.4 | 缓存与会话 |
| bcryptjs | 密码哈希 |

### 部署

| 技术 | 用途 |
|------|------|
| Docker + Docker Compose | 容器化编排 |
| Nginx | 反向代理 + 静态文件服务 |
| jwilder/nginx-proxy | 自动路由（按域名分发到容器） |
| Let's Encrypt + acme-companion | 免费 SSL 证书 + 自动续签 |

## 系统要求

| 项目 | 最低 | 推荐 |
|------|------|------|
| CPU | 1 核 | 2 核 |
| 内存 | 1 GB | 2 GB |
| 磁盘 | 20 GB | 50 GB SSD |
| 操作系统 | Ubuntu 18.04+ / CentOS 7+ / Debian 10+ | |
| 内核 | ≥ 3.10 | ≥ 5.10 |

## 部署模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| Docker + SSL（推荐） | 全自动部署，自动申请 Let's Encrypt 证书 | 生产环境 |
| Docker + HTTP | Docker 部署，无证书 | 本地测试、无域名环境 |
| PM2 本地部署 | 不依赖 Docker，直接运行 Node.js | 无 Docker 环境的服务器 |
