# 前台使用指南

本文档面向最终用户，介绍如何在 HmwCard 前台浏览商品、完成支付和管理订单。

## 首页

访问网站根地址即可进入首页：

```
https://your-domain.com
```

首页展示：
- 轮播图（Banner）
- 推荐商品
- 商品分类导航
- 系统公告

## 浏览商品

### 商品列表

按分类浏览商品，每个商品卡片显示：
- 商品图片
- 商品名称
- 商品标签（如"热销"、"新品"）
- 价格
- 库存状态

### 商品详情

点击商品进入详情页，可查看：
- 完整商品描述
- 商品图片（支持多图）
- 价格信息
- 套餐选项（如有）
- 库存数量

## 下单流程

### 1. 选择商品

在商品详情页点击「立即购买」。

### 2. 选择套餐（套餐商品）

如果是套餐商品，需要先选择套餐时长：
- 月卡（30 天）
- 季卡（90 天）
- 年卡（365 天）
- 自定义套餐

### 3. 选择支付方式

支持的支付方式：

| 支付方式 | 说明 |
|----------|------|
| 支付宝 | 扫码支付 / 手机网页支付 |
| 微信支付 | 扫码支付（国内） |
| PayPal | 海外用户 |
| Stripe | 支持信用卡、Alipay、WeChat Pay |

### 4. 创建订单

确认价格和支付方式后，系统创建订单并跳转到支付页面。

### 5. 完成支付

根据支付方式不同：
- **支付宝**：扫描二维码或跳转到支付宝 App
- **微信**：扫描二维码
- **PayPal**：跳转到 PayPal 登录并确认
- **Stripe**：在 Stripe Checkout 页面完成支付

### 6. 获取卡密

支付成功后，系统自动发放卡密：

- 页面直接显示卡密
- 如页面关闭，可通过订单查询功能重新获取

## 订单查询

### 查询入口

首页导航栏点击「订单查询」。

### 查询方式

输入订单号查询订单状态：

```
/order/query?orderNo=XXXXX
```

### 订单状态

| 状态 | 说明 |
|------|------|
| 待支付 | 订单已创建，等待付款 |
| 支付中 | 支付处理中 |
| 已完成 | 支付成功，卡密已发放 |
| 已取消 | 订单超时或用户取消 |
| 已退款 | 已发起退款 |

### 订单详情

查询结果展示：
- 订单号和创建时间
- 商品名称和价格
- 支付方式和支付时间
- 卡密信息（已完成订单）

## 支付结果页

### 支付成功

```
/payment/success?orderNo=XXXXX
```

显示：
- 支付成功提示
- 卡密信息
- 使用提示

### 支付失败

```
/payment/failed?orderNo=XXXXX
```

显示：
- 失败原因
- 重新支付按钮
- 联系客服入口

## 公告中心

查看系统最新公告：

```
/announcements
```

点击公告标题查看详情。

## 常见问题

### 支付成功但没收到卡密？

1. 等待 30 秒后刷新页面（系统自动发货需要少量时间）
2. 通过订单查询功能查看订单状态
3. 如仍未收到，联系客服并提供订单号

### 支付页面打不开？

1. 检查网络连接
2. 尝试更换支付方式
3. 清除浏览器缓存后重试

### 卡密无法使用？

1. 确认卡密输入正确（注意大小写、区分 0 和 O）
2. 联系客服并提供订单号，客服可协助处理

### 如何申请退款？

请联系客服处理退款，需要提供：
- 订单号
- 退款原因
- 支付凭证（如有）

## 安全提示

- 卡密请妥善保管，泄露后无法追回
- 支付时确认金额和商品信息
- 不要在公共网络环境下支付
- 如遇异常订单，及时联系客服

## 移动端适配

HmwCard 前台完全响应式，支持：
- 手机浏览器访问
- 平板设备
- 微信内嵌浏览器
- 支付宝内嵌浏览器

所有功能在移动端均可正常使用。
